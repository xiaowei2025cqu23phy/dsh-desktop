# 手机 PWA 遥控 · 特色功能指南

> 手机浏览器打开远程地址即用的"遥控 App",与电脑端同一审批/提问队列。

## 快速开始

1. 电脑端 **设置 → 远程访问** → 启用(默认 2 小时后自动关闭,可在设置调整过期策略);
2. 手机与电脑同一局域网,扫设置面板二维码(或访问 `http://<电脑IP>:3083`,端口以设置为准);
3. PWA 自动填入地址与令牌;**添加到主屏幕**当作 App 使用。

> 安全:仅可信局域网;Bearer token + 设备审批 + RPC/文件白名单;禁止内网穿透暴露。

## 特色模块

### 1. 工作区优先的新对话
- 与 harness Web 一致:**先选择/新建工作区,再创建对话**;
- 新会话自动落入所选工作区分组;预设工作区根也可直接作为工作区;
- 会话自动重连后回到原会话,不丢现场。

### 2. 会话权限与消息模式
- 新会话可选 **工作区可写 / 完全访问**(对应 harness `/permission`,需较新版本 harness);
- 消息模式:**排队 / 插入发送**(打断当前等待);
- 侧边栏底部 **🗄 已归档**:归档的会话可一键「↩ 恢复」(恢复后回到原工作区分组;桌面端托管服务时自动刷新,外部托管时重启后生效)。

### 3. 文件浏览与预览
- 只读浏览工作区与预设根目录(白名单外 403);
- 文本分片加载、Markdown 渲染、图片直显;
- 视频(mp4/webm)/音频/PDF 走 Range 流:视频可拖进度;PDF 因手机浏览器禁内嵌,提供「新窗口打开/下载」;
- 面包屑支持逐级回退,超出白名单自动停。

### 4. 手机壁纸
- 内置壁纸一键切换;
- **从手机相册上传图片设为壁纸**(≤12MB,png/jpeg/webp/gif/bmp),与桌面端主窗口壁纸体系打通。

### 5. 断线自动重连
- 网络抖动/飞行模式后指数退避自动重连(1s→15s),恢复后自动重载当前会话;
- 长时间无法恢复会提示在电脑端重新启用远程访问(远程访问 2 小时自动关闭策略)。

### 6. 远程设置(手机端可管理)
- 预设工作区根目录(查看/浏览添加;移除需桌面端确认);
- 定时任务、重启 Harness(需桌面端确认)、会话缓存开关、用量与审计查看。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机连不上 | 同 WiFi、电脑远程访问已开启、端口可达;远程访问到期请在桌面端重开 |
| 视频不能播放 | 确认运行 0.6.0+(旧版 Range 响应缺陷);仍不行把文件路径发我 |
| PDF 打开是下载页 | 手机浏览器不支持内嵌 PDF,属正常,用"新窗口打开" |
| 界面像旧版 | PWA 需要刷新一次(打包版本更新后强制刷新:设置→清除连接信息重连,或浏览器清缓存) |
| 壁纸上传失败 | 图片 ≤12MB 且为支持格式;上传到电脑端需桌面端在线 |

## 桌面端联动

- 审批/提问:手机与桌面/机器人同队列,任一端应答即可;
- harness 命令模板:设置 → 服务 → 启动命令支持「官方最新/官方指定版本/本机仓库」一键选择;
- 网关回归测试:`node scripts/test-remote.mjs`(鉴权 401/媒体流 206/越权 403/打包新鲜度)。
