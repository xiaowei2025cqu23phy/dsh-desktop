# QQ 机器人远程控制 · 完整指南

> DeepSeek Harness Desktop 的 QQ 机器人通道:用 QQ 收发任务、聊天、审批与提问。
> 涉及手机 PWA 的部分见 [PWA 指南](PWA.md)。

## 一、它能做什么

| 场景 | 用法 | 说明 |
|---|---|---|
| 一次性任务 | `任务 分析这个仓库的架构` | 未指定工作区时自动进入你的「默认任务会话」并复用 |
| 指定工作区任务 | `任务 @qqbot 修复登录 bug` | 在该工作区新建任务会话 |
| 指定目录任务 | `任务 目录:D:/work/proj 编译并跑测试` | 任意目录 |
| 强制另起任务会话 | `任务 新:统计今天写了多少行` | 不并入默认任务会话 |
| 连续对话(朋友模式) | 直接发消息 | 只保留一条默认对话线程,穿插任务/工作区不会另开;`新对话` 另起 |
| 工作区对话(助手模式) | `进入 qqbot` | 先列出该工作区会话(状态+时间+摘要)供选择 |
| 继续某工作区会话 | `进入 qqbot 2` | 编号与列表一致 |
| 新建工作区会话 | `进入 qqbot 新` | |
| 查看任务进展 | `进展 session-xxx` | 显示阶段:🤔思考 / 🔧工具 / 💬输出 / ✅完成 + 产物提示 |
| 查看会话内容 | `打开 session-xxx` | 完整最近一轮 |
| 查看/导出会话 | `会话` / `导出 session-xxx` | 会话列表带摘要;导出存桌面端 `exports/` |
| 任务现场播报 | `播报` / `静音` | 默认静默;开启后每 25 秒推一条进展摘要 |
| 审批应答 | 按钮 `✅允许/❌拒绝` 或 `允许`/`拒绝` | |
| 提问应答 | 按钮或 `选 2` / `选 1 3` / `选 自定义:…` | |
| 定时任务 | `定时 10分钟 检查更新` / `定时 每天9:00 写日报` | 仅私聊 |
| 其他查询 | `状态` `工作区` `会话` `模型` `用量` `目录 <路径>` `文件 <路径>` | |

> 💡 推送原则:机器人只在 **进入/查询/审批/任务完成或失败** 时主动推送,其余时刻安静;
> 想看任务过程发 `播报` 或 `进展 <会话id>`。
> 群聊安全:群里**只聊天、不响应任何命令**——任何人@机器人都会触发,等于把电脑交给群成员。

## 二、部署与配置(发布给他人前必读)

1. **注册机器人**:QQ 开放平台 → 应用管理 → 创建机器人(选择「C2C 个人」/群聊能力,按需开通)。拿到 `AppID / AppSecret`,填入桌面端 **设置 → QQ 机器人**;也可用「扫码登录」自动绑定。
2. **平台权限(重要,容易踩坑)**:
   - **主动消息权限**:未开通时,机器人只能"回复"用户消息(回复窗口内)。本程序会自动采用"回复最近一条消息"的方式,不开权限也能对话;但**任务完成/审批等主动通知**在用户长时间没说话时会失败。要完整体验,请在开放平台申请开通**群聊/单聊主动消息**权限。
   - **内联键盘(按钮)**:审批「允许/拒绝」、提问选项、任务操作按钮依赖该能力,随机器人能力一起开通。
   - **群聊**:机器人需被拉入群,并在平台侧开通群聊消息接收。
3. **安全边界**:
   - 机器人**只能由电脑主人添加**到群/好友列表。任何群成员@机器人都会触发回复,**切勿把不可信机器人/不可信群当成自己的通道**——那等于把电脑的 agent 能力交给对方(文件、任务、审批都由 harness 权限策略兜底,但请保持最小信任面)。
   - 48 小时主动窗口:QQ 官方要求 bot 只能在用户交互后的窗口内主动推送;窗口过后需用户先发消息。
   - 主动消息权限申请通过后,若仍提示 `40034105 主动消息失败,无权限`,多为权限位未生效/需重新上线。
4. **默认设置**:设置页可配默认对话模式(autoChat)、主动汇报开关、默认工作区/目录、角色设定。

## 四、会话与工作区模型(便于理解行为)

- **默认对话(纯对话)**:每人一条线程,`~/.dsh 之外不碰文件`,放在「机器人对话」工作区,手机/桌面可见;`新对话` 重开。
- **群聊对话**:每群一条(与私聊隔离),也只聊天;落在「机器人对话」工作区。
- **默认任务会话**:未指定工作区的 `任务` 自动复用每人一条,减少"一次性会话刷屏";`任务 新:` 另起。
- **工作区会话**:`进入` 列表/编号选择,或 `任务 @工作区` 创建;会出现在该工作区的会话列表中。
- **归档**:归档=仅隐藏(日志保留);归档的对话若仍是活动会话,下次发消息会自动开新对话。

## 五、常见问题(FAQ)

| 现象 | 原因与处理 |
|---|---|
| 群消息没反应 | 1) 机器人没开主动消息权限时,只能回复用户消息——先发一条让机器人回复,再等回复;2) 权限位刚开通可能未生效,重启机器人连接(设置里重开一次 QQ 机器人) |
| `40034105 主动消息失败,无权限` | 未开通主动消息权限(见上);开通后重启机器人 |
| `40034005 回复消息msg_id已过期` | 回复窗口超时(约 10 分钟)。本程序自动改用「该群/该用户最近一条消息」回复,通常不会再出现;仍出现说明对方长时间未互动 |
| 任务队列卡住/积压 | 0.6.0 起任务完成会正确落库并放行队列;旧版本积压的条目可在桌面端任务队列手动取消/重试一次 |
| 进展显示"Let me think…"之类思考文本 | 旧版本把模型推理当回复展示;0.6.0 起一律取最终交付文本 |
| 中转站/GLM 模型回复中断 | 提高 read_timeout(≥120s)或关闭流式测试;见桌面端「状态」失败提示里的排查顺序 |
| 电脑关机/退出后机器人无响应 | 机器人跑在桌面端主进程里,需桌面端在线;退出桌面端前 QQ 机器人会断开 |
| 手机上找不到群聊对话 | 群聊是独立对话,不在任何业务工作区;在「机器人对话」工作区或 PWA「🤖 机器人对话」置顶组查看 |
